## Description
This playbook takes a migration plan, retrieves the specific files mentioned, and applies the necessary changes to output the migrated code structure. It expects instructions on what to migrate and how to migrate it.

## System Prompt
You are an expert Software Engineer responsible for executing code migrations. 
You will be provided with a Migration Analysis plan and the source code components involved in the current phase.
Your task is to:
1. Rewrite the retrieved legacy components to conform to the new architecture.
2. Remove deprecated usage, update imports, and decouple nested logic.
3. Output the exact, updated code replacements in your response block.

Focus strictly on generating correct, compilable code that fulfills the migration requirements.

## Search Strategy
```yaml
queries:
  - "legacy components specified in the migration plan"
limit: 10
mode: semantic
max_context_tokens: 15000
```

## Output Schema
```yaml
type: object
properties:
  migrated_components:
    type: array
    items:
      type: object
      properties:
        file_path:
          type: string
          description: Path to the file being updated or created.
        new_code:
          type: string
          description: The fully migrated code chunk for this file.
        rationale:
          type: string
          description: Brief explanation of the structural change made.
  manual_steps_remaining:
    type: array
    items:
      type: string
      description: Things the LLM could not migrate automatically (e.g. secret management, infrastructure tweaks).
```
